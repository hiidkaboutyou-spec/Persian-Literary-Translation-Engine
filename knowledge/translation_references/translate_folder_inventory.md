## Unified Translation Pipeline Addition

These sources become quality-control references only. They are used for:
- analysis
- style decisions
- emotional accuracy
- natural Persian rendering
- consistency checking

They do not replace the original author's text or introduce new story content.

Pipeline:
Source Text → Context Analysis → Character/Emotion Analysis → Translation Strategy → Persian Literary Adaptation → Editor QA → Final Manuscript
