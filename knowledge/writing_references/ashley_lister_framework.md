# Ashley Lister — Writing Reference Framework

Source reference:
How to Write Erotic Fiction and Sex Scenes — Ashley Lister

Purpose inside this project:
This is a craft reference layer only. It is not a story source and does not generate original scene content.

## Integrated principles

### 1. Scene purpose
Every mature/intimate scene must have a narrative function:
- character revelation
- relationship development
- emotional turning point
- conflict or resolution

### 2. Character first
Track:
- motivation
- fears
- boundaries
- expectations
- emotional consequences

### 3. Pacing system
Analyze:
- build-up
- tension changes
- emotional beats
- aftermath

### 4. Editorial checks
Avoid:
- mechanical translation
- losing character voice
- unnecessary exaggeration
- removing psychological meaning

Pipeline usage:
Reference -> analysis rules -> quality control -> Persian literary adaptation
