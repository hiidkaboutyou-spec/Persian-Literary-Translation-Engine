# Diana Gabaldon — Writing Reference Framework

Source reference:
I Give You My Body... How I Write Sex Scenes

Purpose inside this project:
A craft-analysis reference for understanding how intimate scenes support character, emotion and storytelling.

## Integrated principles

### 1. Emotional core
The system must track:
- vulnerability
- trust
- character history
- emotional shifts

### 2. Scene as narrative
Intimate moments are analyzed as part of the larger story:
- before state
- scene change
- after state

### 3. Sensory and psychological balance
Quality review checks:
- emotional clarity
- character consistency
- natural flow
- avoidance of artificial writing

### 4. Translation application
Used for:
- rhythm evaluation
- character voice preservation
- editorial review

Not used for:
- copying style
- replacing author intent
- creating unrelated content
