# Unified Intimacy Quality System

## Inputs
- source scene
- character bible
- relationship history
- translation memory

## Analysis layers

1. Narrative function
2. Character psychology
3. Emotional continuity
4. Voice preservation
5. Rhythm and pacing
6. Persian literary readability

## Quality gates

Before final output:

- Does the scene serve the story?
- Are characters consistent?
- Are emotions clear?
- Is dialogue natural in Persian?
- Were important narrative elements preserved?

## Architecture

Source text
→ Scene analyzer
→ Character brain
→ Emotional continuity brain
→ Translation engine
→ Editor review
→ Manuscript export
