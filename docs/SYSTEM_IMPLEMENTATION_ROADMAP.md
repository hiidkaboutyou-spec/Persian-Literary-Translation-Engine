# System Implementation Roadmap

## Goal
Build a Rust-first literary translation engine for professional Persian fiction workflows.

## Current Architecture

- Literary translation pipeline
- Character memory
- Glossary system
- Translation memory
- Intimacy analysis layer
- Knowledge base architecture

## Next Implementation Block

1. Knowledge ingestion pipeline
2. Supabase retrieval layer
3. Rust domain modules
4. Semantic search
5. Quality evaluation engine
6. Document publishing pipeline

## Design Rules

- Preserve author intent
- Preserve character voice
- Keep project memories isolated
- Use references as methodology, not source text
