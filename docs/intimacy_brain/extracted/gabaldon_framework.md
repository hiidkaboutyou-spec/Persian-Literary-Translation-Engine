# Diana Gabaldon Framework Extraction (Conceptual)

Purpose: translate intimate writing principles into literary adaptation checks.

## Core Principles

- Emotional truth is central to the scene.
- Physical description must support character experience.
- Intimacy scenes affect plot, relationships, and characterization.

## Translation Rules Derived

1. Emotional Continuity
- Track emotional state before, during, and after a scene.
- Preserve changes in trust, closeness, conflict, or vulnerability.

2. Point of View Preservation
- Keep the original narrative distance.
- Preserve what the viewpoint character notices and understands.

3. Sensory and Psychological Balance
- Do not replace emotional meaning with only physical description.
- Do not remove meaningful internal reactions.

4. Quality Review
- Is the character voice intact?
- Is the emotional consequence preserved?
- Does the Persian version create the same narrative experience?

## Usage

This framework guides literary translation analysis and editing decisions.
