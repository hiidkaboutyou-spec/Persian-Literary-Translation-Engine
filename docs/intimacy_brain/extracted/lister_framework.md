# Ashley Lister Framework Extraction (Conceptual)

Purpose: convert writing methodology into translation/editorial rules.

## Core Principles

- Treat intimate scenes as narrative scenes, not isolated events.
- Preserve character motivation, emotional stakes, and relationship context.
- Evaluate scene purpose before wording decisions.
- Maintain continuity of character behavior and established dynamics.

## Translation Rules Derived

1. Scene Function Analysis
- Identify why the scene exists in the story.
- Preserve conflict, vulnerability, attraction, fear, trust, or relationship change.

2. Character-Based Description
- Description should follow character perception.
- Avoid generic wording that removes individual voice.

3. Pacing Control
- Preserve buildup, pauses, hesitation, and emotional transitions.
- Do not compress important emotional beats.

4. Editorial Review Questions
- Does the translation preserve character intent?
- Does dialogue maintain subtext?
- Does the scene remain consistent with previous chapters?

## Usage

This is an analytical framework for translation quality control, not a content generator.
