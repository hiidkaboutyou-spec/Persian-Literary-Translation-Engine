# Supabase Knowledge Schema

The database layer stores reusable translation intelligence.

Tables:

- knowledge_sources
  - books
  - guides
  - reference material

- glossaries
  - terms
  - preferred translations
  - notes

- character_bibles
  - voice
  - personality
  - continuity information

- translation_memory
  - previous decisions
  - context

- scene_analysis_memory
  - narrative function
  - emotional context
  - relationship state

- embeddings
