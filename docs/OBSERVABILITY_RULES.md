# Observability Rules

## Purpose

Keep debugging useful while protecting private literary content.

## Can Be Recorded

- component name
- operation status
- timing information
- error type
- version information

## Cannot Be Recorded

- original story text
- translated output
- character dialogue
- uploaded documents
- private user notes

## Sentry Usage

Sentry integration must use filtering before sending events.

A privacy layer must run before telemetry leaves the machine.
