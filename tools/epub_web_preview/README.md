# Local EPUB web preview

Build a self-contained, local web reader from an EPUB generated by the translation engine.

This tool is a **diagnostic/review surface**, not the canonical editor and not the publication renderer. It is useful for quickly checking chapter order, Persian RTL reading flow, mixed-script readability, navigation, and gross content loss before deeper EPUB/PDF validation.

## Usage

```bash
python tools/epub_web_preview/build_preview.py path/to/book.epub
python3 -m http.server 8765 -d output/interactive-preview
```

Then open the generated book folder through the local server.

The default output lives under `output/`, which is ignored by Git.

## Privacy and security

- The generated preview contains full book text.
- It has no remote network dependencies.
- Source EPUB scripts, iframes, forms, event handlers, external links, audio and embedded objects are not copied into the preview.
- Do not commit, upload, or publish previews automatically.
- This tool does not send text to TTS, an LLM, or any external service.
- It does not mutate the EPUB or project Book IR.

## Scope

Adapted from the useful local-static-preview and chapter-delivery ideas in `DozenTwelve/Papermorph` (MIT). The Papermorph SVG animation engine, quizzes, Edge TTS and Opus-specific authoring flow are intentionally not dependencies of this project.

Permanent publication truth remains the native Book IR + EPUB/DOCX publishing contracts and EPUBCheck.
